IFNOTUS CONTROL PANELS — REDESIGN BRIEF
=======================================
Use this as the source of truth for UI/UX redesign (customer cPanel + staff WHM).
Product: IFNOTUS — Ghana hosting company. Brand wordmark IFNOTUS. Mark: “IF”.
Tagline: Hosting with an AI engineer.
Currency: GHS. Audience: people who want a site live in minutes, not server admins.

TWO PRODUCTS IN ONE
-------------------
1) CUSTOMER PANEL  (cPanel analogue)
   URL: /account
   Who: paying customers. Isolated site workspace only.
   Feel: calm, consumer hosting. Like Hostinger / SiteGround simplified, not WHM.
   Never expose infrastructure: no VPS IP, no server hostname, no /srv paths, no nginx filenames.

2) STAFF PANEL  (WHM / control-plane analogue)
   URL: /panel
   Who: IFNOTUS operators. Full server + all customers.
   Feel: dense ops dashboard. Dark/light. Sidebar. Health, inventory, kill-switches.

3) PUBLIC MARKETING SITE
   URLs: /  /plans  /signup  /login
   Funnel into customer panel. Not a cPanel. Keep brand consistent.

HARD PRODUCT RULES (do not violate in mockups)
----------------------------------------------
- Customers never see the server IP. Domains use nameservers only:
    ns1.ifnotus.space
    ns2.ifnotus.space
- Every new site gets an included hostname:
    env-XXXXXXXX.customers.ifnotus.space
  HTTPS is automatic on *.ifnotus.space. Padlock is on by default.
- Professional/custom domains (studio.online etc.) are add-on names that share the site files.
  Customer points NS to IFNOTUS. No A-record-to-IP instructions.
- FTP for FileZilla: host ftp.ifnotus.space  port 21  type FTP
  If WordPress asks for FTP hostname: localhost
- Database host for apps: localhost
- One FTP account per site, chrooted to that site folder only.
- One database per site when WordPress/Laravel is installed.
- Isolation: each customer environment is a jail (folder + optional container). Copy must say “your site”, never “the server”.
- Plan accent color tints the whole customer workspace (one color per package).
