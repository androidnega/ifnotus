APPENDIX A — AUTOMATIC HOSTING ACCOUNT NAMES
=================================================================

Every hosting environment must receive a clean, short, unique hosting name generated automatically by IFNOTUS.

The customer must NEVER be asked to choose this name.

The system must NEVER stop with:
"hosting name already exists"

Instead, IFNOTUS must automatically generate the next available valid name.

PURPOSE
-------
The hosting name is a human-readable operational identifier for staff/server work.

Example:

Environment UUID:
dc784620-5982-4ae2-b8ff-b8734dde1205

Hosting Name:
manuelhost

The UUID remains the permanent technical database identifier.

Use hosting_name for:
- staff display
- search
- logs
- support
- backups
- server operations
- hosting lists

SOURCE PRIORITY
---------------
1. Custom domain label
   csdttu.online -> csdttu
   votebridge.online -> votebridge
   manuelcode.com -> manuelcode

2. Student hostname
   kwofie.ifnotus.space -> kwofiehost

3. Customer surname
   Kwofie -> kwofiehost

4. Customer first name
   Manuel -> manuelhost

RULES
-----
- lowercase
- a-z and 0-9 only
- must start with a letter
- no spaces
- no underscore
- preferably no hyphen
- readable
- globally unique
- recommended max length: 12 characters

COLLISION HANDLING
------------------

manuelh2
manuelh3
manuelh4

HostingNameService

- migration scripts
