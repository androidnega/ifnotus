1. WHAT IFNOTUS IS (PRODUCT STRUCTURE NOW)
--------------------------------------------------------------------------------

IFNOTUS is a Ghana-focused hosting PLATFORM, not just a web server panel.

LAYERS (top → bottom):

  A) CUSTOMER / STAFF BROWSERS
        ↓
  B) IFNOTUS UI  (Vue 3 + Vite)
        - Public site / plans / checkout
        - Customer portal + hosting panel (/go/hosting, tenant cPanel-like UI)
        - Staff control plane (cpanel.ifnotus.space)
        - File manager, domains, DB studio, stacks, billing screens
        - Branding stays YOURS — customers never need a raw panel login
        ↓
  C) IFNOTUS API  (FastAPI at /srv/apps/ifnotus, port 8010)
        - Auth, customers, orders, MoMo / Paystack billing
        - Packages, coupons, renewals, tickets
        - Student hostnames, reserved labels, hosting_name
        - Provisioning orchestration
        - HostingProvider interface (engine switch)
        ↓
  D) HOSTING ENGINE  (pluggable)
        - TODAY (live):     "legacy"  = nginx + unix users + IFNOTUS provisioning
        - TARGET (planned): "ispconfig" = ISPConfig 3 remote API
        - PARKED:           "olspanel"  = OLSPanel (attempt stopped)
        ↓
  E) OS / DATA ON THE VPS
        - /srv/apps/ifnotus              → control plane code
        - /srv/apps/ifnotus-customers    → paying/student TENANT files
        - /srv/apps/csdttu, quizsnap, …  → YOUR product apps (not tenants)
        - PostgreSQL (ifnotus DB), MySQL (sibling apps), Redis
        - nginx on :80/:443 (live again)
        - BIND named for DNS zones
        - Postfix / Dovecot / Roundcube mail

RESPONSIBILITY SPLIT:

  IFNOTUS owns forever:
    - Billing (MoMo, Paystack, invoices, renewals)
    - Plan catalog & pricing
    - Student / reserved hostname rules
    - Custom UI look & feel
    - Extra features (AI, stacks UI, Flask/Django/React app engine UX)
    - Ghana / business logic

  ENGINE (ISPConfig when live) owns:
    - Linux clients / web domains
    - SSL, FTP, mail mailboxes, MySQL DBs (as configured)
    - Disk / resource templates
    - DNS records (if we migrate DNS into ISPConfig later)

RULE: Browser never talks to ISPConfig. Only IFNOTUS backend holds remote API secrets.
