2. OPEN HOSTING FROM IFNOTUS ACCOUNT
--------------------------------------------------------------------------------

Customer logs into:

https://ifnotus.space/login

Customer selects:

Manage Hosting

Flow:

IFNOTUS authenticated customer
        ↓
verify customer owns hosting environment
        ↓
create short-lived one-time SSO handoff
        ↓
redirect to:
https://cpanel.yalleydadzie.online/sso?token=...
        ↓
customer-domain control plane validates token
        ↓
token consumed once
        ↓
tenant panel session created
        ↓
redirect to:
https://cpanel.yalleydadzie.online/

The user must NOT end up at:

https://ifnotus.space/hosting/<uuid>

7. CUSTOMER DNS — PRIMARY MODE
--------------------------------------------------------------------------------

Preferred setup:

Customer changes the authoritative nameservers at their registrar to:

ns1.ifnotus.space
ns2.ifnotus.space

Once delegated, IFNOTUS automatically manages the DNS zone.

Customer should NOT normally be instructed to copy:

80.241.223.82

into several A records.


IFNOTUS should automatically create/manage:

@          Website
www        Website
cpanel     Tenant control panel
webmail    Tenant webmail
mail       Mail services

MX         Mail exchanger
SPF        Sender policy
DKIM       Mail signing
DMARC      Mail policy


8. EXTERNAL DNS MODE
--------------------------------------------------------------------------------

Only when the customer deliberately keeps:

Cloudflare
Registrar DNS
Other DNS provider

show the required DNS records.

This is the secondary/manual mode.

Do not expose the server IP unnecessarily if a stable hostname/CNAME can safely be used.

Where apex-domain DNS technically requires A/AAAA records, explain that clearly.
