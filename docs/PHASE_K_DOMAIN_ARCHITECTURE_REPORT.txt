1. ARCHITECTURE (AS IMPLEMENTED)
--------------------------------------------------------------------------------

Customer entry (all tenants):
  https://{domain}/cpanel
  https://{domain}/mail  → mail.ifnotus.space (shared Roundcube)

nginx on each tenant vhost:
  location = /cpanel → 302 https://ifnotus.space/go/hosting?host=$host

Portal SPA (/go/hosting):
  1. Read ?host= from query (or legacy cpanel.<domain> normalized to apex)
  2. If unauthenticated → /login?mode=panel&redirect=/go/hosting?host=…
  3. GET /customers/panel-alias?host=… (authenticated)
  4. Ownership check: env.domain OR CustomerDomain must match caller
  5. router.replace → /hosting/{environment_id}
