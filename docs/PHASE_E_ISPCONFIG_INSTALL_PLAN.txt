3. SELECTED approach (controlled)
--------------------------------------------------------------------------------
Official stable tarball + expert non-interactive install.php:

  https://www.ispconfig.org/downloads/ISPConfig-3-stable.tar.gz
  → ISPConfig 3.3.1p1
  php install.php --autoinstall=/root/ifnotus-secrets/ispconfig-autoinstall.ini

Expert flags (intent):
  install_mode=expert
  http_server=nginx
  configure_mail=n          # keep Postfix/Dovecot/Roundcube as-is
  configure_dns=n           # keep authoritative BIND as-is
  configure_firewall=n      # keep Phase A UFW as-is
  configure_webserver=y     # required for panel + future web engine
  install_ispconfig_web_interface=y
  ispconfig_port=8081
  ispconfig_use_ssl=y
  ignore_hostname_dns=y
  join_multiserver_setup=n

MySQL:
  Create root@127.0.0.1 with password + GRANT OPTION (keep root@localhost
  auth_socket for local admin CLI). Installer connects via 127.0.0.1.

FTP:
  Pure-FTPd packages already present; installer will configure/enable them
  (expected for ISPConfig). Customer default remains SFTP via IFNOTUS (Phase D).

Jailkit / Fail2ban:
  Fail2ban already active — installer may touch its ISPConfig jails.
  Jailkit configured only if package present / detect allows.
