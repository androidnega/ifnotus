1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase V establishes the independent Modern Application Hosting Runtime Engine.

Core Principles:
  - "Do NOT force ISPConfig to become Render/Railway."
  - "Build IFNOTUS application runtime separately."
  - "Static SPA builds should not require permanent Node processes."

Runtimes and Frameworks Supported:
  1. Python Runtime:
     - Frameworks: Django (gunicorn/wsgi), Flask (gunicorn/wsgi), FastAPI (uvicorn)
     - Specs: Isolated virtualenv, custom runtime versions, requirements/pyproject parsing,
              dynamic port binding, environment variables injection, systemd unit generation,
              isolated process boundaries, and reverse proxy routing.
  2. Node Runtime:
     - Frameworks: Express, NestJS (node dist/main.js), Next.js (npm run start), SvelteKit (node build)
     - Specs: Isolated directory, custom start commands, environment variables, systemd daemonization,
              and reverse proxy routing.
  3. Static SPA Runtime:
     - Frameworks: React, Vue, Svelte, static HTML
     - Specs: Zero permanent Node process requirement, Nginx `try_files` SPA routing,
              static asset caching headers.
  4. PHP Runtime:
     - Frameworks: Laravel, WordPress, generic PHP
     - Specs: Handled via PHP-FPM pools and Composer dependency structures.
